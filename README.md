# Автотесты для API сервиса «Самокат» (Яндекс Практикум)

Проект содержит пакет автоматизированных тестов для REST API учебного сервиса «Самокат». Тесты покрывают основные ручки управления курьерами и заказами, включая позитивные сценарии и валидацию негативных ответов бэкенда.

##  Стек технологий
* **Python 3.10+** — основной язык разработки.
* **Pytest** — фреймворк для написания и запуска тестов (с использованием параметризации и фикстур).
* **Requests** — библиотека для отправки HTTP-запросов к API.
* **Allure Report** — инструмент для генерации наглядных отчетов о тестировании.

---

##  Структура проекта
* `tests/` — папка с тест-кейсами, разбитыми по логическим модулям (создание, логин, удаление курьеров, управление заказами).
* `helpers/` — вспомогательные методы (генераторы случайных данных курьеров, методы авторизации).
* `data/` — конфигурационные файлы, URL эндпоинтов и константы.
* `conftest.py` — общие фикстуры Pytest для подготовки окружения (создание и автоматическая очистка тестовых данных).
